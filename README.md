# Rolemaster Fieldbook

A small static companion for Rolemaster FRP character sheets and attack table lookup. It runs directly in a browser and can be hosted from the root of a GitHub Pages repository.

## Run locally

Open `index.html` in a modern browser, or serve this folder with any static web server. No build step or package install is needed.

## Publish with GitHub Pages

1. Push the files in this folder to a GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select the branch containing these files and the `/ (root)` folder, then save.

The character roster is stored in browser local storage. It is available in the same browser and on the same device where each character was created. The attack table viewer opens pages 221–231 of the included core rules PDF.

## Current scope

The sheet records identity, race, profession, realm, temporary and potential stats, common skills, armor, experience, and notes. The book's detailed development point costs, racial modifiers, stat bonus calculations, and skill progression remain references for the player and GM; the site does not calculate those rules.
