# Generated browser assets

Generated by wasm-bindgen 0.2.129 from rust/src/lib.rs; do not hand-edit.
Keep rolemaster_core.js, rolemaster_core_bg.wasm and both declaration files together
in version control and publish with the static site. This preserves branch-based
GitHub Pages hosting without installing Rust on the hosting service.

Rebuild from the repository root with npm run build:wasm (see rust/README.md).
Generated glue resolves the binary relative to import.meta.url, including project
subpaths. Serve .wasm as application/wasm. No API server or external CDN is required.
